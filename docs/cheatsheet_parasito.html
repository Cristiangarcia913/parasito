ISA Reference Card · Lenguaje de Programación Esteganográfico · v1.0
⚠ USB CONTAGIADO / ACTIVO ESOLANG · ESTEGANOGRAFÍA VECTOR FÍSICO DE INFECCIÓN
Capa 1
🐍 Anfitrión
Python lo ejecuta normalmente. El comentario es ignorado.
Capa 2
🦠 Parásito
La VM ejecuta palabras en posición IMPAR (1ª, 3ª, 5ª…)
Capa 3
👻 Fantasma
La 1ª letra de cada palabra PAR forma un acróstico oculto.
🔬
REGLA DE LA IMPARIDAD — Comentarios como texto técnico con doble fondo:
# Limpiar Nodo   Almacenar Usuario   "LOS_NUMEROS" Modulo   Unir Buffer   "SON_SOLO" Entrada   Expresar Red   Linea Sistema
→ Parásito ejecuta: limpiar → guardar "LOS_NUMEROS" → unir "SON_SOLO" → mostrar → salto   |   Fantasma: NUMBERS
📋 TABLA DE INSTRUCCIONES — ISA COMPLETA
Cat. Comando Principal Sinónimos válidos Descripción
MEM limpiar resetear, borrar Resetea acumulador, variables y resultado de salida.
MEM guardar <val> almacenar, setear, asignar Carga <val> en el acumulador (literal o variable).
MEM archivar <var> registrar, guardar_var Guarda el acumulador en la variable <var>.
MEM recordar <var> cargar, recuperar Carga la variable <var> en el acumulador.
ARITH sumar <val> adicionar, incrementar Acumulador ← Acumulador + <val>
ARITH restar <val> sustraer, decrementar Acumulador ← Acumulador − <val>
ARITH multiplicar <val> escalar Acumulador ← Acumulador × <val>
ARITH dividir <val> partir Acumulador ← Acumulador ÷ <val> (seguro contra ÷0)
ARITH unir <val> concatenar, anexar Acumulador ← Acumulador + str(<val>) — concatenación.
FLOW destino <id> etiqueta, marca, nodo Define etiqueta de salto <id> (invisible en ejecución).
FLOW saltar <id> ir, brincar Salto incondicional → <id>
FLOW revisar <id> evaluar, comprobar, validar Salto condicional → <id> solo si Acumulador > 0
I/O mostrar imprimir, expresar, revelar Imprime el acumulador en la salida del Parásito.
I/O espacio blank Añade un espacio en blanco a la salida.
I/O salto linea Añade un salto de línea \n a la salida.
INF secreto <msg> ocultar ⚠ Escribe .parasito_secret.txt en el Escritorio con <msg>.
INF infectar <ruta> propagar, infiltrar ⚠ Inyecta código Parásito en el archivo <ruta> objetivo.
